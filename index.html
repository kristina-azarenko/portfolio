Опыт

Проектирую интерфейсы для B2B-платформ, корпоративных веб-сервисов и AR/VR-решений, в том числе для РЖД и СИБУР. Провожу UX-исследования, формирую гипотезы вместе с командой, создаю дизайн-системы и веду дизайн-ревью после разработки.

Первый опыт в UX/UI-дизайне: разрабатывала макеты и концепции интерфейсов в Figma, улучшала UX-сценарии и проводила конкурентный анализ ключевых экранов веб-сервисов компании.

Кейсы

Mobile B2B Android iOS

Переработка корпоративного приложения для работы с почтой и файлами. Упростила навигацию по папкам, переключение модулей и добавила всё, что раньше работало только на десктопе.

Website UX/UI B2B

Пересобрала корпоративный сайт IT-компании TOR: сократила с 27 до 19 страниц, ввела сегментацию по ролям клиентов и добавила калькулятор стоимости.

AR B2B Android Desktop

Сотрудников на секретных объектах раньше вели за руку. Спроектировала AR-приложение для самостоятельной навигации по маршрутам и десктопную админку для операторов.

3D B2B Desktop

Первый цифровой инструмент обучения для инженеров СИБУРа. Заменил выезды на объект интерактивным 3D-тренажёром с режимами разреза, анимации аварийных сценариев и изучения компонентов.

VR Game

Командная разработка VR-игры в жанре tower defense с магическими механиками. Отвечала за игровой UI, HUD, магическую книгу для изучения комбинаций.
